# Behavioural Design Toolkit

A collection of behaviourally-backed UI components designed to improve user engagement through principles from behavioural science.

## What it does

- Pre-built React components informed by behavioural psychology
- Ready-to-use engagement patterns (nudges, defaults, social proof, etc.)
- Accessible component primitives via Radix UI

## Tech stack

- **Frontend:** React + TypeScript + Vite
- **UI:** shadcn/ui + Radix UI
- **Styling:** Tailwind CSS
